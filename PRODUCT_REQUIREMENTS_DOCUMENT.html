1. EXECUTIVE SUMMARY & VISI PRODUK

1.1 Latar Belakang Masalah

Struktur Data dalam pemrograman Python (List, Tuple, Set, dan Dictionary) merupakan kompetensi inti Kurikulum Merdeka Informatika Fase F (Kelas XI). Siswa sering mengalami hambatan kognitif dalam memahami:

  • Mutabilitas vs Immutabilitas: Kebingungan membedakan objek yang dapat dimodifikasi langsung di memori (List/Set/Dict) dengan objek konstan read-only (Tuple).
  • Model Pengindeksan & Hash Table: Miskonsepsi saat mencoba mengindeks Set (set[0]) atau menggunakan tipe data yang unhashable sebagai Kunci Dictionary.
  • Operasi Diagram Venn: Kesulitan mengimplementasikan aljabar himpunan (Union, Intersection, Difference, Symmetric Difference) ke dalam kode Python.
  • Struktur Bersarang (Nested Data): Kerumitan navigasi indeks bertingkat pada List of Dictionaries dan matriks 2D.
  • Keterbatasan Media Teks: Bahan ajar statis minim visualisasi RAM dan tidak menyediakan evaluasi galat instan.

1.2 Visi Produk

Menjadi media laboratorium digital mandiri yang menggabungkan modul kurikulum terstruktur, visualisasi state memori interaktif, engine eksekusi Python lokal on-device, asisten bimbingan AI Tutor berbasis Gemini API, dan gamifikasi terintegrasi.

2. SASARAN PENGGUNA & USER JOURNEY

  • Siswa SMA Kelas XI (Primary Learner): Membutuhkan media belajar visual mandiri di HP, sarana coding langsung tanpa laptop, serta bantuan diagnosa error interpreter seketika.
  • Guru Informatika (Educator / Mentor): Membutuhkan media diferensiasi pembelajaran digital yang selaras dengan Capaian Pembelajaran (CP) Informatika dan terstandarisasi CPython 3.11.

3. SPESIFIKASI KEBUTUHAN FUNGSIONAL

3.1 Modul Kurikulum 4 Struktur Data & Dasar Pemrograman (50+ Materi)

  • List Module (14 Topik): Karakteristik dynamic array, zero-indexing, negative indexing, slicing [start:stop:step], append vs extend vs insert, pop vs remove vs del, Timsort (sort vs sorted), list 2D (matriks), dan list comprehension.
  • Tuple Module (9 Topik): Immutability & efisiensi RAM, single-element tuple trailing comma (1,), tuple unpacking & swapping (a, b = b, a), defensive programming, dan tuple sebagai kunci dictionary hashable.
  • Set Module (10 Topik): Keunikan nilai tanpa duplikat, jebakan {} (dict) vs set(), eliminasi duplikat cepat O(n), operasi Venn (|, &, -, ^), metode aman .discard() vs .remove(), dan larangan set[0].
  • Dictionary Module (12 Topik): Pemetaan Key-Value, aturan kunci unik & hashable, akses aman dict.get(k, default), penugasan dict[k]=v & .update(), looping .items()/.keys()/.values(), dan operator penggabungan | (Python 3.9+).
  • Nested Structures & Perbandingan (5 Topik): List of Dictionaries, Dictionary of Lists, Matriks 2D, Matriks Perbandingan 4 Struktur Data, dan Decision Flowchart.

3.2 Visual State Engine (Visualisasi Memori Interaktif)

  • List & Tuple RAM Visualizer: Diagram blok memori linier interaktif dengan pointer indeks positif dan negatif.
  • Set Venn Diagram Visualizer: Diagram Venn dua himpunan dengan penyorotan area dinamis untuk operasi himpunan.
  • Dictionary Hash Map Visualizer: Visualisasi pemetaan slot Compact Hash Table kunci-nilai.
  • Nested Tree & 2D Grid Visualizer: Representasi visual struktur pohon bertingkat dan tabel matriks baris-kolom.

3.3 Engine Eksekusi Python & Code Playground

  • On-Device Python Interpreter: Eksekusi sintaks Python lokal langsung di perangkat Android tanpa server backend.
  • 13 Tantangan Koding Terintegrasi: Studi kasus koding per modul dengan verifikasi output otomatis, petunjuk (hint), dan reward +15 XP.
  • Full Playground: Editor kode bebas dengan kontrol Jalankan, Format, Reset, dan Simpan Snippet favorit.

3.4 Asisten Belajar Cerdas (AI Python Tutor powered by Gemini)

  • Context-Aware Multi-Turn Consultation: Memahami topik modul aktif (topicTitle), kode playground siswa, riwayat percakapan, dan hasil eksekusi.
  • Bedah Galat & Error Otomatis: Analisis terverifikasi untuk SyntaxError, IndexError, KeyError, TypeError, ValueError, dan IndentationError.
  • Resiliensi Multi-Model & Streaming: Streaming teks instan dengan fallback otomatis antara gemini-3.5-flash, gemini-3.1-pro-preview, gemini-3.1-flash-lite-preview, dan offline ground-truth engine.

3.5 Gamifikasi, Kuis & Evaluasi

  • Sistem XP & Leveling: Novice (0 XP) → Apprentice (100 XP) → Pythonista (300 XP) → Code Wizard (600+ XP).
  • Evaluasi Kuis Formatif: Soal pilihan ganda per modul dengan evaluasi skor instan dan pembahasan lengkap.
  • 9 Achievement Badges: Lencana penghargaan saat menguasai setiap modul dan tantangan koding.

4. KEBUTUHAN NON-FUNGSIONAL

  • UI/UX & Aksesibilitas (M3): Standar Material Design 3, minimum touch target ≥ 48dp, kontras ramah mata, dan proteksi insets keyboard.
  • Performa: Cold-start < 1.2 detik, eksekusi Python lokal < 100 ms, dan rendering UI 60 FPS tanpa jank.
  • Offline-First Persistence: Penyimpanan seluruh data progres belajar secara lokal di Android Room Database (SQLite).
  • Keamanan Kredensial: Kunci API diamankan via Secrets Panel/BuildConfig tanpa eksposur di source code.
